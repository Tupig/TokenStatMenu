# 安装与使用

[返回文档中心](Home.md)

## 适用范围与准备

TokenStatMenu 面向已经在本机运行并登录 Seasun Token Hub 的用户。应用只读取现有连接与会话，不负责企业登录，也不会替换 Hub 或修改 Codex 的网关设置。

| 项目 | 要求 |
| --- | --- |
| 系统 | macOS 13 或更新版本 |
| 芯片 | Apple Silicon 或 Intel；本机构建默认生成当前架构，另有 Universal 构建模式 |
| 企业额度 | 本机 Seasun Token Hub 正常运行、已有有效登录且后台可访问 |
| 本机 Token 记录 | 本机 Codex 产生可识别的用量记录，且当前 provider 配置可与 Hub 的 origin 关联 |
| 从源码构建 | 原生工程使用完整 Xcode 15+；SwiftPM 使用与锁定传递依赖 manifest 兼容的工具链，不能仅以支持 Swift 5.9 判断；Python 3 用于验证与文档工具，详见[编译指南](编译指南.md#固定测试依赖与跨工具链锁) |

**普通使用不需要配置文件、接口文档、API Key 或辅助功能授权。** 辅助功能仅用于可选的界面快照兼容读取，后台直接读取不依赖它。

## 选择安装方式

| 方式 | 适合谁 | 需要留意 |
| --- | --- | --- |
| Homebrew 源码安装 | 已有 Homebrew 和完整 Xcode，希望用 brew 更新 | 构建本机架构，安装/升级后手动启动 |
| 正式 Release 的 Universal App | 希望使用发布产物 | 先核对实际发布资产、校验和及签名说明；当前采用 ad hoc 签名 |
| 从仓库源码构建 | 需要开发、调试或复现构建 | 可选 SwiftPM 组装脚本或原生 Xcode 工程 |

正式版本以 [项目发布页](https://github.com/Tupig/TokenStatMenu/releases) 实际存在的文件为准；工作流或本地 `dist/` 存在并不表示远端已经发布。流水线和资产定义见 [CI/CD](CI-CD.md)，实际本机与发布验收见 [验证记录](../VALIDATION.md)。

## Homebrew 安装

需要满足 Homebrew 自身的主机支持范围，并安装已完成首次启动准备的完整 Xcode 15 或更新版本；仅 Command Line Tools 不能满足此 Formula 的构建要求。正式 Release 和 tap pin 就绪后：

```bash
brew install Tupig/tokenstatmenu/tokenstatmenu
tokenstatmenu
```

Formula 从已校验的正式源码 ZIP 构建原生 App，安装在 Homebrew `libexec`，使用无参数启动器打开稳定 `opt` 路径。构建只在自身进程选择 Xcode，不更改全局 `xcode-select`，不自动启动/关闭应用、不复制到个人应用目录、不修改偏好或系统权限。

App 本地 ad hoc 签名，不是 Developer ID 或 Apple 公证。签名结构通过不代表系统或企业策略一定允许启动；遇到阻止应核实来源和策略，不绕过系统保护。更多配方、更新验证与卸载说明见 [tap 文档](https://github.com/Tupig/homebrew-tokenstatmenu#readme)。

## 下载正式 App

在 [发布页](https://github.com/Tupig/TokenStatMenu/releases) 选择实际存在的 `TokenStatMenu-<版本>-universal.zip`，同时下载同一 Release 的 `release-manifest.json` 和 `SHA256SUMS`。当前 1.1.4/build6 历史 Release 是 ZIP-only；如果下一版 1.1.5/build7 的 DMG 已经在发布页出现，还应下载 `TokenStatMenu-1.1.5-universal.dmg` 并按 manifest/SHA256SUMS 核对。manifest 列出版本/构建、标签提交、App ZIP、源码 ZIP 与 DMG（如适用）的摘要；在同一目录用系统工具核对下载文件的 SHA-256，例如：

```bash
shasum -a 256 TokenStatMenu-1.1.4-universal.zip
```

`1.1.4` 仅说明文件命名规则，实际以所选 Release 为准。将结果与同一版本 `SHA256SUMS` / manifest 对应条目逐字核对后解压。该校验用于发现损坏或资产不一致，不能代替 Apple 信任验证。退出旧 TokenStatMenu 后，再通过 Finder 保留并打开已确认路径的 App；保留前一版本便于回退。

### 使用下一版 DMG（仅当发布页实际提供）

DMG 是包含同一 Universal `TokenStatMenu.app` 和 `/Applications` 别名的安装包装。双击已核对的 DMG 后，将 `TokenStatMenu.app` 拖到“应用程序”文件夹，再从复制后的固定路径打开；DMG 本身不会自动启动、退出、替换或重启任何已有实例。替换旧副本前先从菜单栏退出旧 TokenStatMenu，并保留旧副本作为回退。

DMG 验证只绑定镜像成员、App 四文件树、版本/构建、来源提交、arm64/x86_64 架构和严格 ad hoc 签名；它不授予辅助功能权限、不读取 Hub/Codex 数据、不修改偏好，也不是 Developer ID 签名或 Apple 公证。若发布页没有该文件，继续使用当前实际存在的 ZIP，不要从本地 `dist/` 或草稿推断正式 DMG 已发布。

## 从源码构建

```bash
git clone https://github.com/Tupig/TokenStatMenu.git
cd TokenStatMenu
./script/build_and_run.sh --build-only
open dist/TokenStatMenu.app
```

`--build-only` 创建 `dist/TokenStatMenu.app`，不会启动应用，也不会关闭已经运行的实例。SwiftPM 构建遵守已审核的精确依赖锁，首次可能下载测试依赖；正式 App 运行时不链接这些测试库。必要 pin 缺失或冲突会失败，不需要填写企业配置修复它；工具链与锁定规则见 [编译指南](编译指南.md)。

需要长期保留本机构建时，可先从现有应用菜单退出旧实例，再用 Finder 将新 App 复制到个人“应用程序”目录，并从固定位置打开。保留上一版本便于回退。开发构建采用 ad hoc 签名；这与 Developer ID 签名及 Apple 公证不同。若系统提示来源或签名问题，请核实构建来源与签名状态，见 [常见问题](常见问题.md)，不要绕过系统保护。

## 首次启动

1. 正常打开并登录 Seasun Token Hub，确认它自己的用量页面可用。
2. 打开 TokenStatMenu。它不会弹出主窗口或自动打开面板。
3. 点击右上角菜单栏中的 TokenStatMenu 统计文字，打开概览。
4. 等待首次后台读取完成，再确认“Token Hub 企业额度”的来源状态、5 小时、7 天和月度字段。启动瞬间显示等待连接属于异步读取过程。
5. 正常使用 Codex 后，再查看“本地记录用量”。有两条足够新鲜、连续的活动累计事件时，才会出现实时估算。

后台只返回部分窗口时，应用仅展示已确认的窗口；缺少的字段保持未知。Hub 登录过期、连接异常、多实例或数据结构不受支持时，会显示具体状态，不要求用户填写一个替代接口。

## 菜单栏显示

标题按当前可用证据显示速度、记录量和企业窗口，例如：

```text
实时≈24.5tok/s · 小计19.1K · 未核验1 · Hub 5h剩75% / 7d剩30%
```

以上数字是说明格式的虚构示例，实际标题随数据完整度变化：

- `实时≈…tok/s`：本机活动事件的输出速度估算，时效为最后事件后 15 秒。
- `上轮均:…tok/s`：无新鲜实时证据时，使用完整轮次的记录均速，包含工具、网络和等待。
- `上轮均:—`：没有足够证据计算速度。
- `Σ` 或“小计”：本次扫描范围内的记录核算，不是企业全部用量。
- “未核验”：存在无法可靠核算的线程或文件；不把它们当作零。
- `Hub 5h剩… / 7d剩…`：仅在 Hub 快照仍有效且对应窗口存在时附加。

将指针停在菜单栏文字上可查看来源、扫描范围和记录时间等说明。完整定义见 [统计口径](统计口径.md)。

## 概览与偏好

| 区域 | 应如何理解 |
| --- | --- |
| Token Hub 企业额度 | 后台金额窗口、剩余百分比、重置时间及月度已用；与本地 Token 分开 |
| 本地记录用量 | 输入、输出、总 Token 小计，已核验/未核验线程、顶层对话、子代理/分叉，速度与事件时间 |
| 本地历史额度（非企业当前额度） | 默认折叠的辅助说明；展开查看未核验账号/组织的历史已用比例、观察时间及原重置时间，缺失窗口保持缺失 |
| 右上角设置按钮 | 切换到可选偏好，再次点击返回概览 |
| 右上角电源按钮 | 退出 TokenStatMenu，不退出 Token Hub 或 Codex |

偏好只有刷新间隔和界面兼容读取开关。无需修改默认值即可使用，详见 [可选偏好](../CONFIGURATION.md)。关闭兼容读取不关闭企业后台直接读取。

## 系统权限列表仍显示默认图标

先确认固定安装副本内有 `Contents/Resources/AppIcon.icns`，且版本是本次构建；检查方法见 [编译指南](编译指南.md)。图标文件可解码而系统设置列表仍显示旧默认图标时，可只重新登记这一个固定 App：

```bash
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister \
  -f "$HOME/Applications/TokenStatMenu.app"
```

如果安装位置不同，将参数替换成已经核对的那一份 App 路径。该命令只登记指定应用，图标资源与授权开关保持原状。随后从系统设置菜单正常退出“系统设置”，重新打开并回到原权限列表，让列表重新读取图标；保留原有授权状态。

本机曾出现资源与 Bundle 读取正确、系统图标解析的部分尺寸仍为默认图标的情况；针对性登记后，独立原生解析与实际权限列表均显示新图标。图标解析、权限是否开启、后台用量是否连接是三项独立检查。无需为图标问题重置权限、清理全局缓存或重新授权。

## 更新与确认版本

Homebrew 用户先从 TokenStatMenu 面板退出旧实例，再执行：

```bash
brew update
brew upgrade Tupig/tokenstatmenu/tokenstatmenu
tokenstatmenu
```

升级只更新磁盘文件，不替换运行中的进程。旧实例不退出时，系统可能只激活旧版本，且 Homebrew 可能清理其旧 keg。不要同时从手工副本和 Homebrew 路径启动。手工副本和个人偏好会保留，可在退出 brew 版本后打开旧副本回退。

手工安装用户先退出当前 TokenStatMenu，再替换固定位置的 App 并重新打开。版本和构建号以 App 内 `Contents/Info.plist` 为准；构建还写入公开源码 revision 与状态。Homebrew 源码包构建使用 `release-source`，不会冒充 `clean` Git 工作区。检查方法见 [编译指南](编译指南.md)。

当前没有“开机启动”设置或 App 内自动更新器；tap 自动跟进 Release 不会自动升级你机器上的 App。若需要登录时启动，可使用 macOS 系统“登录项”管理，并指向已确认的固定 App 路径。
