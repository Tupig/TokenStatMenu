## 环境

只支持 Apple Silicon（M 系列）、macOS 13+。原生 Xcode 工程与 Homebrew 构建要求完整 Xcode 15+；SwiftPM 开发构建和测试要求 Swift 6.1+（通常为 Xcode 16.3+），因为依赖 manifest 使用较新工具链。正式 App 仅链接系统框架，SnapshotTesting 等依赖只用于测试，Python 只用于脚本。

```bash
git clone https://github.com/Tupig/TokenStatMenu.git
cd TokenStatMenu
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
swift --version
```

这只为当前终端选择工具链，不改变全局 `xcode-select`。

## 主 App 开发构建

```bash
./script/build_and_run.sh --build-only
open dist/TokenStatMenu.app
```

此模式通过 SwiftPM 组装当前架构的 Debug App，不含 Widget 扩展。`--release` 改用 Release 并启动，不是只构建模式。

本地构建会先运行 `bump_build.py`，同步递增 App 和小组件的 `CFBundleVersion`。失败也不回退 build。`TOKENSTAT_SKIP_BUILD_BUMP=1` 可供检查脚本保持源码不变；版本/build 可用 `python3 -B script/bump_build.py --print` 查看。

## 带小组件的本机开发版

```bash
./script/build_and_run.sh --dev-widget
```

需要本机 Apple Development 身份。脚本从证书 Subject OU 取得 Team ID，默认 group 为 `<TEAMID>.com.tupig.TokenStatMenu`。可覆盖：

| 变量 | 用途 |
| --- | --- |
| `TOKENSTAT_TEAM_ID` | 签名团队 |
| `TOKENSTAT_WIDGET_GROUP` | 已获授权的 App Group |
| `TOKENSTAT_INSTALL_DIR` | 安装目录，默认 `~/Applications` |

此模式替换目标目录中的开发副本，并重启 TokenStatMenu、小组件扩展和 `chronod`。不要拿它替代 Homebrew 升级，也不要指向存有未备份手动副本的目录。

## 发布构建

```bash
TOKENSTAT_WIDGET_GROUP=<已配置的组名> \
  ./script/build_and_run.sh --arm64
lipo -archs dist/TokenStatMenu.app/Contents/MacOS/TokenStatMenu
codesign --verify --deep --strict dist/TokenStatMenu.app
```

`--arm64` 使用 Xcode 原生工程构建主 App 和内嵌扩展，输出 arm64，不启动，也不递增已提交 build。旧 `--universal` 名称仅保留为兼容入口；1.1.7 起不再生成 Intel slice。

占位 group 必须换成当前构建实际配置。写入组名和 entitlements 不代表 Apple 授权成立；公开包目前仍是 ad hoc 签名，小组件分发权限见 [#88](https://github.com/Tupig/TokenStatMenu/issues/88)。

## Xcode 与工程生成

```bash
open TokenStatMenu.xcodeproj
```

选择共享 `TokenStatMenu` Scheme。工程和 Scheme 由 `script/generate_xcode_project.py` 维护，修改生成逻辑后再生成，不只修改输出文件。

## 测试依赖锁

所有 SwiftPM 命令使用 `--force-resolved-versions`。SnapshotTesting 固定 1.19.6，CustomDump 固定 1.6.0，overlay 固定 1.11.0，让本机与 CI 使用同一套依赖，避免新版按工具链切换包身份造成同名 target 冲突。依赖锁缺项或约束冲突时应失败，不删除锁或在构建后偷偷恢复。

```bash
swift package --force-resolved-versions resolve
git diff --exit-code -- Package.resolved
```

部分 CLT/SwiftBuild 版本会输出不存在的开发库搜索路径警告。可用完整 Xcode 对照，或运行 `python3 -B script/diagnose_swift_toolchain.py --toolchain both` 分类；不要把 warning 与编译失败混为一谈。

## 核对产物

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' dist/TokenStatMenu.app/Contents/Info.plist
/usr/libexec/PlistBuddy -c 'Print :CFBundleVersion' dist/TokenStatMenu.app/Contents/Info.plist
/usr/libexec/PlistBuddy -c 'Print :TokenStatSourceRevision' dist/TokenStatMenu.app/Contents/Info.plist
```

脚本组装的发布包包含公开提交和工作区状态；Homebrew 使用已验证 Release 提交与 `release-source`。版本一致不等于当前运行进程来自该路径，运行验收还需检查安装位置。

`python3 -B script/package_source.py` 按显式白名单生成源码 ZIP。新增文件须同步清单，不打包整个目录。[CI/CD](CI-CD.md)说明 DMG 与正式发布步骤。

## Environment

Apple Silicon (M-series) and macOS 13+ only. Native Xcode and Homebrew builds require full Xcode 15+. SwiftPM development builds and tests require Swift 6.1+ (typically Xcode 16.3+) for the dependency manifests. The App links system frameworks only. SnapshotTesting is test-only; Python runs development scripts.

```bash
git clone https://github.com/Tupig/TokenStatMenu.git
cd TokenStatMenu
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
swift --version
```

This does not change global `xcode-select`.

## Main App Development Build

```bash
./script/build_and_run.sh --build-only
open dist/TokenStatMenu.app
```

SwiftPM assembles a Debug App without the widget extension. `--release` builds Release and launches it; it is not build-only.

Local builds run `bump_build.py` first to increment both bundle build numbers. A failed build does not roll back. Checks can set `TOKENSTAT_SKIP_BUILD_BUMP=1` to keep source metadata unchanged. Print identity with `python3 -B script/bump_build.py --print`.

## Local Widget Build

```bash
./script/build_and_run.sh --dev-widget
```

Requires an Apple Development identity. The Team ID comes from the certificate Subject OU; the default group is `<TEAMID>.com.tupig.TokenStatMenu`. Overrides:

| Variable | Purpose |
| --- | --- |
| `TOKENSTAT_TEAM_ID` | Signing team |
| `TOKENSTAT_WIDGET_GROUP` | Authorized App Group |
| `TOKENSTAT_INSTALL_DIR` | Destination, default `~/Applications` |

This replaces the development copy at that destination and restarts TokenStatMenu, its widget and `chronod`. It is not a Homebrew upgrade. Do not point it at an unbacked-up manual copy.

## Release Build

```bash
TOKENSTAT_WIDGET_GROUP=<configured-group> \
  ./script/build_and_run.sh --arm64
lipo -archs dist/TokenStatMenu.app/Contents/MacOS/TokenStatMenu
codesign --verify --deep --strict dist/TokenStatMenu.app
```

`--arm64` builds the App and embedded extension through Xcode, without launching or incrementing the committed build. `--universal` remains a compatibility alias only; 1.1.7 onward has no Intel slice.

Replace the placeholder with the actual group configuration. A group string and entitlements do not grant Apple authorization. Public packages remain ad hoc signed; see [#88](https://github.com/Tupig/TokenStatMenu/issues/88).

## Xcode Project

```bash
open TokenStatMenu.xcodeproj
```

Use the shared TokenStatMenu Scheme. `script/generate_xcode_project.py` maintains the project and schemes; update the generator rather than only its output.

## Dependency Lock

Use `--force-resolved-versions` for SwiftPM commands. SnapshotTesting is pinned to 1.19.6, CustomDump to 1.6.0 and overlay to 1.11.0, keeping local and CI builds on one graph. Newer versions switch package identities across toolchains and can create duplicate targets. Missing pins or conflicting constraints must fail; do not delete or silently restore the lock.

```bash
swift package --force-resolved-versions resolve
git diff --exit-code -- Package.resolved
```

Some CLT/SwiftBuild versions emit missing developer-library search-path warnings. Compare full Xcode or run `python3 -B script/diagnose_swift_toolchain.py --toolchain both`. A warning is not necessarily a build failure.

## Checking the Artifact

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' dist/TokenStatMenu.app/Contents/Info.plist
/usr/libexec/PlistBuddy -c 'Print :CFBundleVersion' dist/TokenStatMenu.app/Contents/Info.plist
/usr/libexec/PlistBuddy -c 'Print :TokenStatSourceRevision' dist/TokenStatMenu.app/Contents/Info.plist
```

Release assembly records the public commit and worktree state. Homebrew records the verified Release commit and `release-source`. Matching metadata does not prove the running process came from that copy; check the installation path too.

`python3 -B script/package_source.py` builds an allowlisted source ZIP. Add new public files explicitly. See [CI/CD](CI-CD.md#cicd-english) for DMG packaging and publication.
