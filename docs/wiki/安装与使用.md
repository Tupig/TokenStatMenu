# 安装与使用

**简体中文** | [English](#installation-and-usage-english)

[文档中心](Home.md) · [常见问题](常见问题.md)

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | macOS 13+；桌面小组件需要 macOS 14+ |
| 芯片 | 仅 Apple Silicon（M 系列），arm64 |
| 企业额度 | Seasun Token Hub 正在运行、已登录，后台可访问 |
| 本地记录 | 可识别的 Codex 用量记录，当前 provider 与 Hub 连接可关联 |
| Homebrew 构建 | Homebrew 与完整 Xcode 15+，已完成 Xcode 首次启动准备 |

TokenStatMenu 不负责登录 Hub，也不改写 Hub 数据库或 Codex 网关设置。正常读取额度不需要辅助功能权限。

## Homebrew 安装

```bash
brew install Tupig/tokenstatmenu/tokenstatmenu
brew test Tupig/tokenstatmenu/tokenstatmenu
tokenstatmenu
```

Formula 下载正式 Release 的源码 ZIP，用 Xcode 编译本机架构。App 安装在 Homebrew 的 `libexec`，启动器使用稳定的 `opt` 路径。安装不会启动 App、关闭旧实例、覆盖手动副本或更改全局 `xcode-select`。

只有 Command Line Tools 时，请先安装完整 Xcode。配方与更新记录见 [Homebrew Tap](https://github.com/Tupig/homebrew-tokenstatmenu)。

## DMG 安装

1. 前往 [Releases](https://github.com/Tupig/TokenStatMenu/releases)，选择所需版本。
2. 下载 `TokenStatMenu.dmg` 和同一 Release 的 `SHA256SUMS`。
3. 运行 `shasum -a 256 <DMG 文件名>`，与对应行核对。
4. 打开 DMG，将 App 拖到“应用程序”。也可用 Finder 复制到 `~/Applications`。
5. 从复制后的路径打开 App，不要一直从挂载的 DMG 运行。

替换旧副本前先退出旧实例。DMG 仅包装 App 和指向 `/Applications` 的别名，不是安装脚本。喜欢 ZIP 的用户也可解压同版 `TokenStatMenu.zip`。1.1.7 起不再提供 Intel 版本。

公开下载和 Homebrew 构建采用 **ad hoc 签名**，尚未做 Developer ID 签名或 Apple 公证。摘要用于核对下载完整性，不代表 Apple 信任。遇到系统或企业策略拦截时，先确认来源和签名，不要关闭系统保护。

## 首次启动

1. 打开并登录 Seasun Token Hub，确认 Hub 自己能显示用量。
2. 打开 TokenStatMenu。应用没有主窗口，也不常驻 Dock。
3. 点击右上角菜单栏数字，等待首次额度读取完成。
4. 在概览中确认来源状态与重置时间；点击齿轮进入设置查看版本和 build。

菜单栏示例：

```text
38.10% | 74.40% | $3,488.22
```

依次是 5 小时已用、7 天已用、月度用量。面板和小组件中的“剩余”比例与菜单栏“已用”相反；它们不是数值不同步。菜单栏不显示本地 tok/s。

## 添加小组件

在小组件图库搜索 TokenStatMenu，只提供 small 尺寸：

- 5 小时、7 天：剩余百分比、已用进度条、最大额度、重置时间。
- 月度用量：只显示已用金额，不画进度条。
- 重置券：显示后台数量，读取失败显示未知。

文字统一 10pt，数据来自主 App 写入的 App Group 快照。WidgetKit 自行安排刷新，不能保证与菜单栏逐秒同时变化；到期或重置后旧值会失效。

> [!IMPORTANT]
> 本机 Apple Development 签名候选已验证共享通道。公开 DMG/Homebrew 的 ad hoc 签名可能无法访问 App Group，显示“共享通道不可用”。这不是刷新频率问题，反复重装或授权辅助功能都不能补上签名权限。见 [#88](https://github.com/Tupig/TokenStatMenu/issues/88)。

## 偏好设置

| 设置 | 默认值与行为 |
| --- | --- |
| 刷新秒数 | 默认 60；范围 15–3600 秒；无效值回到默认值 |
| Token Hub 界面兼容读取 | 默认启用，但不会自动请求辅助功能授权；关闭不影响后台直读 |

点击“保存偏好”才写入；“重新加载偏好”只重读。旧配置中的 API 字段被忽略，主动保存只保留允许的偏好。辅助功能只供可选的界面兼容读取使用。

## 更新与回退

### Homebrew

先从面板的电源按钮退出旧实例：

```bash
brew update
brew outdated Tupig/tokenstatmenu/tokenstatmenu
brew upgrade Tupig/tokenstatmenu/tokenstatmenu
brew test Tupig/tokenstatmenu/tokenstatmenu
tokenstatmenu
```

`brew upgrade` 更新磁盘文件，不会替换运行中的进程。Tap 更新配方也不会替用户自动升级。设置页的版本/build 应与安装版本一致。

### DMG 或 ZIP

下载新版，核对摘要，退出旧实例后替换固定位置的 App。保留上一版副本可供回退；回退前也需退出新版。个人偏好不因替换 App 而删除。

不要同时打开 Homebrew 与手动副本。应用没有内置自动更新器和登录启动开关；需要开机运行时，可在 macOS“登录项”中选择固定副本。

# Installation and Usage (English)

[简体中文](#安装与使用) | **English**

[Documentation](Home.md#documentation-hub-english) · [FAQ](常见问题.md#faq-english)

## Requirements

| Item | Requirement |
| --- | --- |
| System | macOS 13+; desktop widgets require macOS 14+ |
| CPU | Apple Silicon (M-series) only, arm64 |
| Enterprise quotas | Seasun Token Hub running, signed in and able to reach its service |
| Local records | Recognizable Codex usage records whose current provider can be associated with Hub |
| Homebrew build | Homebrew and full Xcode 15+, with first-launch setup completed |

TokenStatMenu does not log in for you, modify the Hub database or change Codex routing. Direct quota reads need no Accessibility permission.

## Homebrew Installation

```bash
brew install Tupig/tokenstatmenu/tokenstatmenu
brew test Tupig/tokenstatmenu/tokenstatmenu
tokenstatmenu
```

The formula builds the host architecture from the official Release source ZIP using Xcode. The App lives under Homebrew `libexec`; the launcher uses the stable `opt` path. Installation does not start the App, stop an old instance, replace manual copies or change global `xcode-select`.

Install full Xcode if you only have Command Line Tools. See the [Homebrew Tap](https://github.com/Tupig/homebrew-tokenstatmenu) for formula changes.

## DMG Installation

1. Choose a version on [Releases](https://github.com/Tupig/TokenStatMenu/releases).
2. Download `TokenStatMenu.dmg` and its `SHA256SUMS`.
3. Compare `shasum -a 256 <DMG filename>` with the matching entry.
4. Open the image and drag the App to Applications, or copy it to `~/Applications` in Finder.
5. Open the installed copy rather than running it from the mounted image.

Quit the old instance before replacing it. The DMG contains the App and an `/Applications` alias, not an installer script. The matching `TokenStatMenu.zip` is an alternative. Intel is unsupported from 1.1.7 onward.

Downloads and Homebrew builds are **ad hoc signed**, not Developer ID signed or notarized. Checksums establish download integrity, not Apple trust. Check the source and signature if macOS or company policy blocks the App; do not disable system protections.

## First Launch

1. Open and sign in to Seasun Token Hub. Check that Hub can show its own usage.
2. Open TokenStatMenu. It has no main window or persistent Dock icon.
3. Click the menu bar figures and wait for the first quota response.
4. Check source status and reset times. Open Settings for the running version and build.

Example menu bar:

```text
38.10% | 74.40% | $3,488.22
```

These are five-hour used, seven-day used, and monthly spend. The panel and widget label their percentages as remaining, the inverse of used. That difference is not a synchronization error. Local tok/s is not shown in the menu bar.

## Adding the Widget

Find TokenStatMenu in the widget gallery. Only small is available:

- Five-hour and seven-day: remaining percentage, used progress, limit and reset time.
- Monthly spend: used amount only, without a progress bar.
- Reset vouchers: service count, or unknown if unavailable.

All text is 10pt. The main App writes an App Group snapshot; WidgetKit schedules refreshes, so updates need not appear in the same second as the menu bar. Expired or reset values are invalidated.

> [!IMPORTANT]
> Sharing has been tested with a local Apple Development-signed candidate. Public DMG/Homebrew ad hoc builds may lack App Group access and show an unavailable channel. Reinstalling, changing refresh intervals or granting Accessibility cannot supply signing authorization. See [#88](https://github.com/Tupig/TokenStatMenu/issues/88).

## Preferences

| Setting | Default and behavior |
| --- | --- |
| Refresh seconds | 60 by default; valid range 15–3600; invalid input falls back to default |
| Hub UI compatibility read | Enabled by default, without an automatic Accessibility prompt; disabling it does not disable direct service reads |

Save writes preferences; Reload only reads them. Old API fields are ignored and omitted on explicit save. Accessibility is only used by the optional UI compatibility reader.

## Updating and Rollback

### Homebrew

Quit the old instance using the panel power button:

```bash
brew update
brew outdated Tupig/tokenstatmenu/tokenstatmenu
brew upgrade Tupig/tokenstatmenu/tokenstatmenu
brew test Tupig/tokenstatmenu/tokenstatmenu
tokenstatmenu
```

An upgrade replaces files, not the running process. Tap updates do not automatically upgrade user installations. Check the running version/build in Settings afterwards.

### DMG or ZIP

Download and verify the new version, quit the old instance, then replace the App at its fixed location. Keep the previous copy for rollback; quit the new version before reopening it. Replacing the App preserves preferences.

Do not run manual and Homebrew copies together. There is no in-app updater or launch-at-login switch; use macOS Login Items with the intended installed copy if needed.
