# 贡献指南

[返回文档中心](Home.md)

欢迎改进文档、统计边界、测试、性能与原生界面。项目使用 [MIT 许可证](../../LICENSE)，正式 App 聚焦 Seasun Token Hub 的自动接入；较大的来源或行为变更应先在 Issue 中明确需求与可验证证据。

## 报告问题

每个确认的问题都应有 Issue，便于跟踪复现、修复和剩余验证。先搜索 [已有 Issues](https://github.com/Tupig/TokenStatMenu/issues)，能复用的应补充既有条目，避免把同一现象拆成重复问题。

可按以下格式提交：

```text
问题：用一句话描述具体异常
环境：应用版本/构建号、macOS 版本、Apple Silicon 或 Intel
来源：Hub 后台直接读取 / 界面兼容快照 / 本地 Codex 记录 / UI
复现：最少操作步骤
预期：应出现的行为
实际：脱敏状态文字、未知/过期等表现
已确认：哪些条件已检查，哪些仅是推测
```

提交数值解析问题时，使用虚构字段和合成数值保留结构，不复制真实响应。性能问题说明空闲/面板打开/有活动事件等场景、测量方法和持续时间；单次 Activity Monitor 数字不宜直接归因于某一函数。

## 公开内容边界

不提交真实 API Key、登录令牌、Hub 数据库、企业地址、账号、组织标识、额度、会话正文、本机绝对路径、运行日志、证书或原始截图。`.gitignore` 不是充分保证：已跟踪文件、Issue 正文和图片同样可能泄露信息。

测试只使用合成身份、虚构域名与受控临时目录。需要界面材料时，从合成数据渲染，不用真实账户截图。隐私处理原则见 [隐私说明](../../PRIVACY.md)，提交前检查见 [测试指南](测试指南.md)。

## 开发流程

1. 以 Issue 明确问题、预期行为与验证范围，先核对当前实现，不把旧文档当作现状。
2. 在自己的分支上修改，将 App 状态、核心解析、界面和文档职责保持清楚。
3. 行为修复应先用有意义的合成回归复现，再实现修复；视觉调整应检查真实 SwiftUI 的浅色/深色结果。
4. 先完成本地测试，再推送；CI 结果另行记录，不能代替本机验收。
5. PR 描述说明问题、最终改变、验证方式及未验证限制，并关联 Issue。

不要添加 Electron 或大体积运行时。新的运行时依赖、来源、配置项或后台任务需要说明必要性、资源成本与数据边界。不要为填补 UI 数值而猜接口、读取不相关凭据或把未知换成零。

## 代码与性能约定

- 主线程负责 AppKit/SwiftUI 展示，文件与网络工作放在受控后台执行。
- 扫描、缓存和重试应有预算，不能无界枚举、循环轮询或积压任务。
- 目标身份、配置或 generation 变化后拒绝旧结果；退出时释放自己拥有的资源。
- 菜单栏仅在内容变化时更新，实时值与详情共用时效判断。
- 记录小计、金额窗口、活动估算与历史均速保持来源和单位分离。
- 性能结论应附同场景的前后测量；减少某次扫描读取不等于已证明整体内存或 CPU 改善。

模块与现有预算见 [实现范围](../IMPLEMENTATION.md) 和 [设计说明](../DESIGN.md)。

## 文档改动约定

文档中心放在 `docs/wiki/Home.md`，专题页使用中文名称。每页提供返回中心和相关页链接，使用带 `.md` 的相对路径，保证 GitHub 源码页可直接点击。代码、参数、默认值和工作流以当前实现为准。

新增功能同步更新首页、统计口径、使用/配置说明与实现矩阵；新增公开文件同步到 `script/package_source.py` 的显式白名单。源码 ZIP 由该清单生成，默认打包不会写入或更新文档。`docs/VALIDATION.md` 记录当前验证范围与限制，不能把未做的检查补写为已通过。

文档的信息组织参考 [TuPigGHD2Chinese 文档目录](https://github.com/Tupig/TuPigGHD2Chinese/tree/main/docs)，只借鉴入口、中心与专题分层，不复制其产品内容。当前 `docs/wiki/` 是仓库内文档，不表示已经自动同步到 GitHub Wiki。

## 提交前核对

| 改动类型 | 至少需要核对 |
| --- | --- |
| 解析与核算 | 有针对性的核心红绿回归、未知/错误输入与覆盖上限 |
| App 生命周期与偏好 | 原生状态回归、隔离启动、无意外外部读取或权限请求 |
| UI | 浅色/深色、留白、截断、焦点与可访问性范围说明 |
| 性能 | 相同输入、模式与采样方法的测量，结果不跨场景泛化 |
| 文档 | 命令与参数对应源码、相对链接有效、未实现能力明确 |
| 所有公开提交 | 差异审阅、白名单、工作区与暂存隐私检查、无真实运行材料 |
