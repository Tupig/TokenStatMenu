# 实现范围与剩余工作

正式 App 已转向 Seasun Token Hub 专用入口：偏好允许列表、安全默认启动、移除通用代理/API/凭据接入、只读来源状态、独立的本地记录与可选界面快照。旧协议组件仅作为核心库历史实现保留。

当前修正按契约先准备真实临时 plist 启动/保存/重新加载检查，再经独立充分性审查进入产品修改。覆盖无配置、旧 proxy、任意或非法旧 endpoint、损坏 plist、新旧 Boolean 优先级、非法数值、安全保存失败、preview 惰性以及全部后台资源禁用。Settings 使用实际 NSHostingView 读取/渲染供审查，不能用静态声明代替 UI 验证。

隔离集成只启动并清理自己的子进程；构建模式不得按进程名关闭用户 App。后台禁用时诊断只能反映未知统计和实际资源状态。核心计量、继承、窗口与 AX 合成回归继续验证既有边界。

未完成：无需新增权限或凭据的真实企业统计连接、准确且来源可核验的 5 小时/7 天重置与月度用量、真实瞬时 token/s、全新安装端到端验证。收敛设置和移除旧路径只完成产品范围修正，不关闭这些需求。公开发布须另经白名单隐私检查、构建、来源清单与运行产物一致性核验。
