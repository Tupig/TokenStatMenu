# 命令行参数

**简体中文** | [English](#cli-options-english)

[文档中心](Home.md) · [编译指南](编译指南.md)

普通使用直接打开 App。App 参数与构建脚本模式是两套入口，不相互转发。

## App 参数

| 参数 | 行为 |
| --- | --- |
| `--config <path>` | 指定本应用偏好位置；启动不自动创建 |
| `--show-panel` | 启动后显式打开面板 |
| `--request-accessibility` | 请求可选界面兼容读取权限，不是后台读取前提 |
| `--disable-background-services` | 关闭后台 I/O，供隔离测试 |
| `--diagnostics-output <path>` | 写本机诊断 JSON；含状态、计数等诊断字段，不应公开原文件 |
| `--test-fixture` | 标记测试语义；单独使用不能隔离全部 I/O |

```bash
open dist/TokenStatMenu.app --args --show-panel
```

没有统一 `--help` 页面；路径参数使用绝对路径并加引号。测试优先用 `script/test.sh`，不要在真实后台启动时注入演示值。

## 构建脚本

只读取第一个模式参数，不支持叠加：

| 模式 | 行为 |
| --- | --- |
| 无参数 / `run` | SwiftPM Debug 主 App，启动 |
| `--build-only` | SwiftPM Debug 主 App，不启动 |
| `--release` | SwiftPM Release 主 App，启动 |
| `--arm64` | Xcode arm64 发布包，含扩展，不启动、不递增 build |
| `--universal` | `--arm64` 的旧名称兼容入口 |
| `--dev-widget` | Apple Development 签名，安装开发副本，重启相关进程并启动 |
| `--verify` | Debug 构建后检查同名进程，不等于 UI 验收 |
| `--debug` | 交给 LLDB |
| `--logs` / `--telemetry` | 本机统一日志流，不上传遥测 |

除发布模式外，构建先同步递增 App/扩展 build。`--dev-widget` 会替换目标开发副本并重启进程，其他模式不会关闭用户 App。

## 环境变量

| 变量 | 用途 |
| --- | --- |
| `DEVELOPER_DIR` | 当前命令使用的 Xcode |
| `CODEX_HOME` | Codex 根目录，只接受绝对路径；Finder 不一定继承终端变量 |
| `TOKENSTAT_WIDGET_GROUP` | 发布/开发签名使用的 App Group |
| `TOKENSTAT_TEAM_ID` | 本机开发签名团队 |
| `TOKENSTAT_INSTALL_DIR` | 开发版安装目录 |
| `TOKENSTAT_SKIP_BUILD_BUMP=1` | 检查期间不递增 build |
| `TOKENSTAT_RECORD_SNAPSHOTS=1` | 显式录制 UI 基线，仅接受视觉变更时使用 |

## 开发工具

| 命令 | 输出 |
| --- | --- |
| `python3 -B script/render_preview.py` | `dist/previews/` 中的合成图像 |
| `python3 -B script/package_source.py` | 白名单源码 ZIP；`--export <目录>` 可另行导出 |
| `python3 -B script/check_docs.py --self-test` | 文档链接、锚点和检查器自测 |
| `python3 -B script/check_public_content.py` | 工作区白名单检查；`--git-index` 检查暂存内容 |
| `python3 -B script/benchmark_menu.py` | 合成菜单热路径基准，不代表整机 CPU 或内存 |
| `python3 -B script/bump_build.py --print` | 当前版本/build，不修改 |

发布工具的 `preflight/package/verify/publish` 见 [CI/CD](CI-CD.md)。只有 `publish` 会写 GitHub Release。

# CLI Options (English)

[简体中文](#命令行参数) | **English**

[Documentation](Home.md#documentation-hub-english) · [Build](编译指南.md#build-guide-english)

Open the App normally for everyday use. App arguments and build-script modes are separate interfaces.

## App Arguments

| Argument | Behavior |
| --- | --- |
| `--config <path>` | App preference path; not created automatically at startup |
| `--show-panel` | Explicitly opens the panel after launch |
| `--request-accessibility` | Requests optional UI-reader access, not service access |
| `--disable-background-services` | Disables background I/O for isolated tests |
| `--diagnostics-output <path>` | Local diagnostic JSON with statuses and counters; do not publish the raw file |
| `--test-fixture` | Marks test semantics; does not isolate all I/O by itself |

```bash
open dist/TokenStatMenu.app --args --show-panel
```

There is no unified `--help` page. Quote absolute paths. Prefer `script/test.sh` for isolation; do not inject demonstration values into a live background session.

## Build Script

Only the first mode argument is read:

| Mode | Behavior |
| --- | --- |
| Default / `run` | SwiftPM Debug main App, launches |
| `--build-only` | SwiftPM Debug main App, no launch |
| `--release` | SwiftPM Release main App, launches |
| `--arm64` | Xcode arm64 release App with extension; no launch/build bump |
| `--universal` | Compatibility alias for `--arm64` |
| `--dev-widget` | Development signing, replaces dev copy, restarts processes and launches |
| `--verify` | Checks a named process after build, not UI acceptance |
| `--debug` | Starts LLDB |
| `--logs` / `--telemetry` | Local unified-log stream, not uploaded telemetry |

Non-release builds increment both build numbers. `--dev-widget` replaces the destination development copy and restarts processes; other modes do not close user Apps.

## Environment

| Variable | Purpose |
| --- | --- |
| `DEVELOPER_DIR` | Xcode for the current command |
| `CODEX_HOME` | Absolute Codex root; Finder may not inherit shell variables |
| `TOKENSTAT_WIDGET_GROUP` | Release/development App Group |
| `TOKENSTAT_TEAM_ID` | Development signing team |
| `TOKENSTAT_INSTALL_DIR` | Development installation directory |
| `TOKENSTAT_SKIP_BUILD_BUMP=1` | Preserve build numbers during checks |
| `TOKENSTAT_RECORD_SNAPSHOTS=1` | Record reviewed UI reference changes |

## Development Tools

| Command | Output |
| --- | --- |
| `python3 -B script/render_preview.py` | Synthetic images in `dist/previews/` |
| `python3 -B script/package_source.py` | Allowlisted source ZIP; optional `--export <directory>` |
| `python3 -B script/check_docs.py --self-test` | Links, anchors and checker fixtures |
| `python3 -B script/check_public_content.py` | Worktree checks; `--git-index` checks staged blobs |
| `python3 -B script/benchmark_menu.py` | Synthetic menu-path benchmark, not whole-App CPU/memory |
| `python3 -B script/bump_build.py --print` | Read-only version/build display |

See [CI/CD](CI-CD.md#cicd-english) for `preflight/package/verify/publish`. Only `publish` writes GitHub Releases.
