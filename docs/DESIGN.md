# TokenStatMenu 设计

macOS 13+；Swift、AppKit、SwiftUI、Network、Foundation、Security、Charts。SnapshotTesting 仅作为测试依赖。
NSStatusItem 常驻标题；NSPopover 承载仪表盘和设置，无默认主窗口、无 Dock 图标、无自动弹窗。

数据来源由配置选择：`localCodex`（新安装默认）有限读取本地 Codex 会话记录；`proxy` 为调用方 → 127.0.0.1 本机代理 → 固定配置的上游 Endpoint。
独立 URLSession 请求企业月度接口，支持点分字段路径；月度数据不与启动后累计混用。
仅统计经过代理的请求，通过白名单读取 Codex 网关非认证字段，不改写 Codex 配置，也不对其他应用做全局 TLS 拦截。

SSE 以行和空行分帧，网络 chunk 不等于 token。中文/ASCII 权重仅用于实时估算。
权威 usage 到达后替换该请求的累计值，不把结算差额注入实时滑动窗口。
使用 monotonic uptime 与 5 秒窗口、100ms 分桶；标题 2Hz，图表 1Hz，最多 600 点。
并发以请求 UUID 隔离。输出速度为所有活跃请求的合计；输入/首输出等待比值标明推算。
Ollama 原生最终 eval_count / eval_duration 另外提供服务端平均速度。

请求：支持 Chat Completions、Responses、Ollama chat/generate，流式及非流式。
HTTP 入口严格限制在回环，需本机随机访问令牌，拒绝非 JSON、未知路径及超大正文。
上游密钥独立保存在 Keychain；请求头白名单；不跟随上游重定向，防止凭据泄露。
解析、网络、日志在后台队列；发送队列有背压上限；取消调用方会取消上游。

统计：启动后累计、失败数、首个响应字节平均延迟与完整请求平均耗时。
费用按每请求开始时 USD/百万 tokens 单价计算；CNY 由用户配置汇率换算。
日志默认关闭，仅写请求 ID、时间、模型、数量、计数来源和耗时，不写密钥、提示词或输出。
10MB 日志轮转；导出当前及上一份日志。

未完成流、缺失 usage、估算、多模态内容无法估算、配额失败/过期均显式标识。
手填总配额只定义上限，不能凭空得到企业已用量；无接口时显示未知。

验收：Swift 测试覆盖解析和统计；本地可控 HTTP 上游验证实际代理返回、错误、并发、配额及取消；
构建 arm64 和 x86_64；本机启动并核对标题和面板；真实企业 API 未配置时不宣称联调完成。

网关发现：启动或手动刷新时做一次有界本地扫描。与网络、计量、日志解耦；候选仅包含来源、provider、Endpoint、模型和是否活动，不携带认证值。导入不同 Endpoint 时清空旧凭据表单，需用户保存才改变网络服务。


本地 Codex 来源：只扫描绝对 `CODEX_HOME/sessions` 或 `~/.codex/sessions`，单扫描完成 5 秒后启动下一次且不重叠。最多枚举 5,000 个目录项、处理 32 个物理文件，每文件读取头部 64 KiB 与尾部 256 KiB、总读取 10 MiB；符号链接和非普通文件跳过。首条完整物理记录必须含有可识别线程身份的 metadata；同 inode 或可证明字节相同的副本去重，同身份冲突且无权威版本依据时整组未知。根线程取最后合法累计贡献；分叉只有在边界及连续基线到最终累计均可证明时才扣除继承量，引用式历史未知。缓存以安全打开后的文件身份为键，并在命中前重新验证描述符包含关系；缓存摘要可暂时包含受限去重身份信息及内容摘要 hash，不包含正文或原始路径，也不持久化。读后身份变化则丢弃本次文件结果。会话字节短暂在内存解析，仅数字、metadata 支持的顶层对话数、已核验/未知/未识别数量及分类、事件时间、最近可验证的已完成 turn 摘要及 quota 窗口快照进入模型。已知贡献显示为当前扫描范围记录小计；未知贡献不按零处理，只有核算完整且扫描未受限时才标为本次扫描记录量。物理文件数不等于对话数。turn 均速需要匹配的开始/完成边界、开始前累计 output 基线及完成前有效累计 output；分母是整轮时长，包含工具、网络和等待，只计会话中记录的 output。它不是瞬时 decode 速度；证据不完整则未知。此模式不调用 Keychain、不启动代理、不访问企业用量接口。UI 明确标记为本次扫描范围记录，不显示请求数、费用或延迟。
