# TokenStatMenu 设计

产品只面向 Seasun Token Hub。AppKit 持有菜单栏条目与弹出面板，SwiftUI 渲染中文界面，AppModel 协调允许的来源与可选偏好。无主窗口，正式运行不需要第三方框架。

## 启动与配置

AppModel 通过窄的偏好加载/保存依赖启动。加载返回原始 plist 字节，允许列表解码仅产生刷新间隔与兼容读取开关。无配置、损坏配置与旧代理字段不阻止启动，也不自动改写文件。正式 App 不读取 Keychain；它只读发现 Token Hub 自有数据库中的连接和 SSO 会话，使用同组织 HTTPS 来源完成内存回调交换和只读额度请求，不启动旧代理或调用任意用户填写的企业 URL。

统一后台开关控制计时器、观察者、本地扫描及自动 AX 调度，供测试隔离。Preview 在任何偏好加载和开关求值之前返回。主动保存先完成原子落盘，再更新内存；失败保持原状态。旧核心协议组件可继续接受独立回归测试，但不驱动正式 App。

## 数值与来源

本地 Codex 扫描是有限范围的记录核算。正式扫描先读取无凭据的 Codex `config.toml` 与 Token Hub `client.connection`，只有当前 `model_provider` 的 `base_url` origin 与 Token Hub 的 AI Manager/AITS origin 相符时才接受 rollout；无法证明时整项保持未知，不把其他 provider 的会话混进来。首条 metadata 确定逻辑线程；重复与冲突版本区分处理，继承贡献只有在连续边界/基线可证时扣除。未知贡献不按零合计。每轮最多枚举 5,000 项、32 文件、每文件头 64 KiB/尾 256 KiB、总计 10 MiB。缓存命中仍验证安全打开后的身份与路由指纹，读取中发生变化则丢弃。

上轮均速使用完整、同一轮次的开始前 output 基线与结束前累计增量，除以有依据的整轮时长；工具、网络与等待都在分母中。活动轮次另从仍未完成的 `task_started` 后两条单调 `token_count.info.total_token_usage` 差分计算实时估算，最后事件超过 15 秒即未知；它不伪装成网关权威时序，也不以刷新频率代替 token。历史窗口不与其他会话拼接，也不当企业当前额度。

Token Hub 界面快照使用独立模型。只在已授予系统信任时读取唯一的额度区域，不操作目标 UI。双读规范化比较、身份校验、节点/字符/时间预算、单扫描调度与 generation 丢弃旧结果限制失效和混合快照风险。金额不转为 Token；来源符号不自动认定币种；短重置文本不猜年份和时区。

## 刷新与失效

菜单内容在主线程低频更新且避免重复绘制；本地扫描完成后至少间隔 5 秒，不积压任务。兼容扫描串行、有界并按偏好间隔重排。退出、权限撤销、目标身份变化、关闭读取和旧 generation 返回都会清除或拒绝快照。诊断从实际资源状态产生，只输出结构和就绪信息。

## Token Hub 直接额度入口

`TokenHubDirectQuotaClient` 从 Token Hub 的 `client.connection` 与 `seasun_sso_session` 读取必要字段，构造固定回调参数并拦截 302。连接和回调只接受 HTTPS、无凭据、同一可注册域名的来源；多标签公共后缀不会被当成组织域。取出短期访问令牌后请求额度接口，请求前后重新读取设置，若会话、连接或数据库身份变化则丢弃响应。解析严格区分 `fixed_5h`、`fixed_7d` 和 `user_month`，不从金额推算 Token，也不把轮询频率当成瞬时吞吐。

## 数据边界

实时估算来自 Seasun 路由 Codex rollout 的本地累计事件，菜单栏明确标记“实时估算”；没有新鲜活动事件时回退为上轮均速或未知。Token Hub 企业额度仍来自只读后台窗口响应，不能从额度金额或刷新间隔推导 token/s。不会为填补数值而读取 Keychain、猜测未确认接口、修改目标应用或混用未核验 provider 的历史小计。
