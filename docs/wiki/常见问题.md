# 常见问题

**简体中文** | [English](#faq-english)

[文档中心](Home.md) · [安装与使用](安装与使用.md)

## 支持 Intel 吗？

不支持。1.1.8 起只支持 Apple Silicon（M 系列），发布包与 Homebrew 构建均为 arm64。旧版 Universal 下载不代表新版仍支持 Intel。

## 菜单栏没有出现

应用没有主窗口，不常驻 Dock。查看右上角菜单栏；刘海、空间不足或菜单栏管理器可能遮挡数字。释放一些空间后重试。若安装过多个副本，先正常退出旧实例，再从固定位置打开。

## 额度为什么是未知？

先确认 Hub 已运行、已登录，且自己的用量页可用。然后看面板状态：

| 状态 | 处理 |
| --- | --- |
| Hub 未运行 | 启动 Hub，等待自动重试 |
| 多个 Hub 实例 | 正常关闭多余实例，不强制结束不明进程 |
| 会话过期 | 回到 Hub 登录 |
| 网络或后台不可用 | 检查企业网络连接，等待下一次刷新 |
| 数据无法核验 | 提交脱敏状态与复现步骤，不发送原始响应 |
| 只缺一个窗口 | 后台可能未提供；不从其他窗口补齐 |

无需手填替代接口或 API Key。辅助功能权限也不能修复后台登录问题。

## 菜单栏有数字，小组件没有

先区分两种情况：

- **共享通道不可用**：签名没有获得 App Group 权限。公开 ad hoc 包可能遇到，见 [#88](https://github.com/Tupig/TokenStatMenu/issues/88)。不是加快刷新或辅助功能授权能解决的。
- **未知或尚未获取**：打开主 App，等首次读取完成。WidgetKit 会调度更新，不保证逐秒跟随；过期时宁可未知，也不保留旧额度。

本机开发请使用带 Apple Development 签名的 `--dev-widget`，不要把 SwiftPM 的主 App-only 包当作带小组件版本。菜单栏显示“已用”，小组件显示“剩余”，两者通常相加为 100%。

## 重置券为零还是未知？

`0 张` 表示后台明确返回零。未知表示接口失败、字段缺失或无效，不能理解成没有券。

## 为什么与 Codex 侧栏或账单不同？

本地扫描有限额，只汇总可核算记录；线程数不是请求数，顶层对话数不是侧栏总数。Hub 返回金额，本地记录提供 Token，两者不能直接比较。见[统计口径](统计口径.md)。

本地活动速率需要连续新鲜事件，停止推进 15 秒后失效。上轮均速包含工具和等待，不等于模型生成速度；菜单栏只显示额度，不再显示速度。

## 要授权辅助功能吗？

正常后台读取不需要。只有使用可选“界面兼容读取”时才需要系统信任；应用不会在启动时主动弹授权。关闭该开关不会关闭后台读取。不要重置 TCC 数据库来处理图标、数据或签名问题。

## Homebrew 没有更新到新版

先 `brew update`，再用 `brew info Tupig/tokenstatmenu/tokenstatmenu` 比较配方版本与 Releases。配方可能仍在跑发布后的检查。确认新版配方就绪后退出旧 App，再 `brew upgrade` 并重新启动。磁盘升级不等于运行进程已更新。

## 构建或快照测试失败

使用完整 Xcode，按[编译指南](编译指南.md)为当前命令指定 `DEVELOPER_DIR`。不要删除依赖锁绕过解析失败。同一 `.build` 不要并发启动多个 SwiftPM 构建。图像差异先人工检查，不要为了测试变绿直接重录。[测试指南](测试指南.md)有完整步骤。

## 怎么反馈问题？

到 [Issues](https://github.com/Tupig/TokenStatMenu/issues) 附上版本/build、macOS、M 系列型号、最少复现步骤和脱敏状态。不发数据库、令牌、企业地址、会话正文、运行日志或未处理的账户截图。

# FAQ (English)

[简体中文](#常见问题) | **English**

[Documentation](Home.md#documentation-hub-english) · [Installation](安装与使用.md#installation-and-usage-english)

## Is Intel supported?

No. Version 1.1.8 onward supports Apple Silicon (M-series) only. Release binaries and Homebrew builds are arm64. Older Universal downloads do not imply support in current versions.

## The menu bar item is missing

There is no main window or persistent Dock icon. Check the right side of the menu bar; a notch, limited space or a menu bar manager may hide it. Free some space. If several App copies exist, quit the old instance and open the intended installed copy.

## Why are quotas unknown?

Check that Hub is running, signed in and displaying its own usage. Then read the panel status:

| Status | Action |
| --- | --- |
| Hub not running | Open Hub and wait for retry |
| Multiple instances | Close extra instances normally |
| Session expired | Sign in through Hub |
| Network/service unavailable | Check required connectivity and wait for refresh |
| Response cannot be validated | Report sanitized status and steps, not the raw response |
| One window missing | The service may not supply it; another window cannot fill it |

Do not enter a substitute endpoint or API Key. Accessibility permission cannot repair service authentication.

## The menu bar has data but the widget does not

- **Unavailable sharing channel** means the signature lacks App Group authorization. Public ad hoc builds may encounter this; see [#88](https://github.com/Tupig/TokenStatMenu/issues/88). Refresh intervals and Accessibility do not fix signing permissions.
- **Unknown or not yet received** means the App needs to finish a read, or WidgetKit has not refreshed. Open the main App and allow the system to schedule an update. Expired data stays unknown rather than reusing old quotas.

For local development, use the Apple Development-signed `--dev-widget` build. SwiftPM main-App-only builds do not include the widget. The menu bar shows used percentages; the widget shows remaining, normally adding up to 100%.

## Zero vouchers or unknown?

Zero means the service explicitly returned zero. Unknown means failure, missing data or an invalid field, not that you have no vouchers.

## Why do figures differ from Codex or the bill?

Local scans are bounded subtotals. Threads are not requests; identified top-level conversations are not the entire sidebar. Hub amounts and local Token counts cannot be directly compared. See [Metric definitions](统计口径.md#metric-definitions-english).

Activity rates require fresh consecutive events and expire after 15 seconds. Completed-turn averages include tools and waits. The menu bar shows quotas only, not rates.

## Do I need Accessibility permission?

Not for direct reads. Only the optional UI compatibility reader needs system trust; startup does not prompt automatically. Disabling it leaves direct reads enabled. Do not reset the TCC database to fix icons, data or signing.

## Homebrew has not picked up a release

Run `brew update`, then compare `brew info Tupig/tokenstatmenu/tokenstatmenu` with Releases. The Tap may still be testing the new candidate. Once the formula is available, quit the old App, upgrade and reopen it. Replacing files does not replace a running process.

## Builds or snapshot tests fail

Use full Xcode with the per-command `DEVELOPER_DIR` from the [Build guide](编译指南.md#build-guide-english). Do not delete dependency locks to bypass failures or run multiple SwiftPM builds in one `.build`. Review image differences before recording references. See [Testing](测试指南.md#testing-guide-english).

## Reporting a bug

Include version/build, macOS, M-series model, minimal steps and sanitized status in [Issues](https://github.com/Tupig/TokenStatMenu/issues). Do not upload databases, tokens, enterprise addresses, conversation text, raw logs or account screenshots.
